# школо! — english, но по кайфу

Игровая образовательная платформа для изучения английского языка.

## Технологии

- React 19 + TypeScript + Vite
- Tailwind CSS
- Vite PWA

## Запуск

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
```

## Доступ и данные

- Приложение открывается сразу, без регистрации, входа, пароля и email-кодов.
- Экраны авторизации и клиент Supabase Auth удалены.
- Используется локальный профиль ученика.
- Прогресс, валюты, покупки и настройки хранятся в `localStorage` текущего устройства.
- Серверной синхронизации между устройствами сейчас нет.

## Контент

- 8 уроков и 48 заданий.
- 6 типов заданий: выбор ответа, ввод, верно/неверно, пары, картинки и аудио.
- Последовательное открытие уровней.
- XP, монеты, кристаллы, магазин, рейтинг, класс и профиль.

## Деплой на Vercel

- Framework Preset: `Vite`
- Build Command: `npm run build`
- Output Directory: `dist`
- Root Directory: `./`
